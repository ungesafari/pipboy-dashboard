# Pip-Boy Dashboard

Personal dashboard (tasks, deadlines, calendar, travel planner, sleep and screen time), styled after Fallout 4's Pip-Boy.
A single HTML file. No server, no build step.

## Use it
Open the GitHub Pages address on your phone and laptop. On the phone, use "Add to Home Screen" for one-tap access.

## Data and privacy
- Nothing personal is stored in this repository. Your data stays in your browser (localStorage).
- **Sync between devices:** Log → Data → *Sync & Connections*. Paste a GitHub fine-grained token with the "Gists: Read and write" permission. The data is stored in a secret gist on your own account.
- **Google Calendar:** Log → Data → *Sync & Connections*. Paste your own OAuth Client ID. This only works from the GitHub Pages address.
